# Airbnb Data Analysis Dashboard (Power BI)

## Overview

This project presents an interactive Power BI dashboard built using the Airbnb Open Data dataset. The dashboard provides insights into listing prices, room types, neighbourhood distribution, availability, and review trends.

## Dashboard Preview

![Dashboard](Airbnb_dashboard.png)

## Key Features

- Interactive Power BI Dashboard
- Price Analysis by Room Type
- Listing Distribution across Neighbourhoods
- Availability Analysis
- Review Trends
- Geographic Visualization using Maps

## Tools Used

- Power BI
- DAX
- Data Modeling

## Dashboard Insights

- Compared average prices across room types.
- Analyzed listing availability throughout the year.
- Explored neighbourhood-wise listing distribution.
- Visualized Airbnb listings geographically using maps.
- Built interactive visuals for business insights.
